# Fix escalation final reply and earlier escalation trigger

## Problem

Current behavior:
- After the user accepts the proposed bank/conditions, the bot may continue consulting.
- The LLM can say “передадим заявку менеджеру” while `handoff=false`.
- Real escalation is triggered only on the next user acknowledgement like “окей жду”.
- The final handoff message is still generated by LLM and may repeat documents or sound verbose.

Observed flow:
- Bot explains TKB FL conditions.
- User: “нормально”, “хорошо”.
- Bot incorrectly sends another generated answer with documents and a manager promise, but `handoff=false`.
- User: “окей жду”.
- Only then Planner returns `ready_to_open`, `handoff=true`, and session silence activates.

## Required fix 1 — Deterministic final handoff reply

When `handoff=true`, do NOT generate the user-facing reply with LLM.

Instead, always send this exact fixed message:

```text
Принял. Передаю вашу заявку старшему менеджеру, чтобы помочь вам дальше.
